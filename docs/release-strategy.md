# Estrategia de release

- Versionado: Semantic Versioning, secuencia hasta `v1.0.0`.
- Ambientes: `dev` (automático desde main) -> `staging` (validación) -> `prod` (aprobación manual).
- Controles: pipeline verde, aprobación en el ambiente y checklist de validación.
- Hitos (equivalen a las entregas parciales): `v0.1.0` fin semana 1, `v0.5.0` fin semana 2, `v1.0.0` fin semana 3.
